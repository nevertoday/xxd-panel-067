# 🦁 XXD Panel 067

### 赤と青の固定インクを使用して、ユーモラスで優しい日常の観察を記録します。

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

Panel 067 は、赤と青の 2 つの手描きインクのみを使用して、非常に薄い紙に手作業によるミスのある斜めの断続的な線で核となるシーンを再現し、注意深くデザインされた個人的な観察ノートのように見せています。

**キーワード:** 固定の赤と青 · 手描きの二重インク · 個人的な観察 · 子どもらしいユーモア · 広い領域の空白

## 使用する

```text
/xxd-panel-067 photo.jpg --mode design-only --size 3:4 --text prompt --locale ja-JP
```

単一画像、ディレクトリ バッチ、4 つの出力モード、複数のサイズ、および 3 つのテキスト モードをサポートします。完全な動作については、[SKILL.md](SKILL.md) を参照してください。
