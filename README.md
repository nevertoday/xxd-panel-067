# 🦁 XXD Panel 067

### 用固定红蓝双墨记录幽默、温柔的日常观察

Panel 067 只使用红色与蓝色两种手绘墨色，在极浅纸面上以歪斜、断续、带手部误差的线条重述一个核心场景，让画面像被认真设计过的私人观察笔记。

**关键词：** 固定红蓝 · 手绘双墨 · 私人观察 · 童真幽默 · 大面积留白

## 使用

```text
/xxd-panel-067 photo.jpg --mode design-only --size 3:4 --text prompt --locale zh-CN
```

支持单图、目录批量、四种输出模式、多尺寸与三种文字模式。完整行为见 [SKILL.md](SKILL.md)。
